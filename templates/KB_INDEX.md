## Usage Protocol

1. Read the task description. Extract the key intent/keywords.
2. Match keywords against the tables below.
3. Load ONLY the listed file paths into your context.
4. If cross-repo info needed → check the **Dep Index** section → load dep KB if fresh.
5. No keyword match → load `product/PRD.md` + `helpers/architecture/overview.md` → then explore source code starting from the entry points listed in the closest workflow.

## Fallback Protocol

If no keyword match is found in any index above:

1. Load `product/PRD.md` for domain context.
2. Load `helpers/architecture/overview.md` for component orientation.
3. If still insufficient → explore source code directly, starting from entry-point files
   listed in the nearest workflow's `entry-points.md`.
4. After exploring, consider updating `KB_INDEX.md` with new keywords for next time.
